# Dra. Marcela Duch — Kit de Assets

Kit preparado para uso em aplicações web e mobile, preservando o monograma MD aprovado.

## Paleta principal

- Marrom institucional: `#5B3828`
- Marrom profundo: `#3E281F`
- Nude principal: `#C7A98D`
- Nude claro: `#E9D8C9`
- Off-white: `#F8F3EE`
- Grafite: `#272321`

## Pastas

- `master/`: arquivo principal em 4K, com transparência.
- `png/`: versões transparentes em tamanhos de interface.
- `webp/`: versões leves para web.
- `app-icons/`: ícones quadrados sem moldura externa.
- `favicon/`: favicons e ícones pequenos.

## Uso recomendado

- Use a versão marrom sobre fundos claros.
- Use a versão branca sobre fundos marrons, escuros ou fotográficos.
- Não distorça, incline, redesenhe ou altere as proporções do monograma.
- Preserve uma área de respiro mínima equivalente à espessura da haste vertical do “M”.
- Para App Store e Play Store, use o PNG 1024 × 1024 da pasta `app-icons`.
